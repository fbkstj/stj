ESET Endpoint Antivirus 與 Management Agent 快速啟用全指南

本指南詳細說明校園與企業環境中 **ESET Management Agent (EraAgentSvc)** 與 **ESET Endpoint Antivirus (ekrn.exe)** 的最佳安裝順序、內外網 VPN 0 秒即時觸發啟用機制，以及 **四大階段自動化健康診斷流程**。
已完整整理為 **Antigravity SKILL 技能規範** 與管理員批次腳本。

核心組件 1 服務：EraAgentSvc

ESET Management Agent（中控代理）

負責與 ESET PROTECT 伺服器進行 TCP 2222 複寫、安全憑證註冊、政策接收與授權派發。為防毒軟體順利啟用的核心通訊橋樑。

核心組件 2 核心：ekrn.exe / egui.exe

ESET Endpoint Antivirus（防毒主程式）

提供本機檔案即時防護、網路攔截、病毒碼更新與掃描引擎。成功取得 Agent 派發之授權後即會轉為綠色「您受到完整保護」。

🚀 快速啟動與授權啟用操作 SOP

1 一鍵強制重啟與授權同步

在校外連上 VPN 後，右鍵點擊 重啟ESET中控同步.bat 選擇「以系統管理員身分執行」，或在 CMD 執行：

net stop EraAgentSvc && net start EraAgentSvc
2 開啟防毒桌面介面 (GUI)

若桌面圖示消失，按 Win + R 輸入並執行：

"C:\Program Files\ESET\ESET Security\egui.exe"
3 PowerShell 全套服務啟動

以系統管理員身分開啟 PowerShell，啟動本機核心與代理：

Start-Service ekrn
Start-Service EraAgentSvc

🩺 四大階段生命週期與健康診斷 SOP

使用 check_eset_phases.ps1 進行分層自動診斷

下載診斷腳本 (ZIP)
階段 1：架構與連線

檢測 ekrn.exe 與 EraAgentSvc 服務狀態，測試中控 TCP 2222 埠連通性。

階段 2：憑證驗證

檢查 status.html 確信 Peer Certificate 載入成功且在有效期限內。

階段 3：排程複寫

查閱 trace.log 確認與 ESET PROTECT 伺服器保持正常 Replication 心跳。

階段 4：授權與防護

確認 WebActivationState 狀態與 WMI 碼 266240 轉為綠色防護。

PowerShell 診斷指令：
powershell -ExecutionPolicy Bypass -File "check_eset_phases.ps1"
