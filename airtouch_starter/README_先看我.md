# AirTouch 無接觸手勢＋語音遙控：學生實作程式包

手油油、手濕、手不方便時，不碰鍵盤滑鼠也能操作電腦：用一顆 USB 鏡頭辨識手勢（MediaPipe 21 個手部關節點），
再加上中文語音指令，控制 YouTube、PowerPoint 簡報、PDF 文件，以及 Teams／Zoom／Google Meet 視訊會議。
程式會看「最前面的視窗」自動切換模式，同一個手勢在不同程式做不同的事。

完整教學（功能設計、應用程式模式、原理、流程、測試、評分）：https://fbkstj.github.io/www/#page/airtouch_project_guide
手冊第 2 章有**情境動畫**與**互動模擬器**，沒有鏡頭也能先在網頁上試手勢規則、語音指令與模式切換。

> 「略過」只會在 YouTube 已經顯示「略過」按鈕時，代替你按下去。程式**不會**封鎖廣告、快轉或跳過不能略過的廣告，
> 這類做法違反 YouTube 服務條款，不要加進專題。

## 一、安裝
0. AI 助手（擇一）：Google Antigravity（免費），或 Claude Code（需 Claude 付費方案）。手冊的提示語兩者通用。
1. 安裝 Python 3.10 以上版本（勾選 **Add Python to PATH**）。
2. 在這個資料夾開啟命令提示字元：`pip install -r requirements.txt`
3. 第一次執行會自動下載手部模型到 `models/hand_landmarker.task`（約 8 MB），需要網路。
4. 語音辨識使用 Google 的線上服務，需要網路；沒有網路或麥克風時，可以用「打字模式」。
5. 準備一顆 USB 網路攝影機（筆電內建鏡頭也可以）與麥克風。

## 二、操作順序
| 檔案 | 說明 |
|---|---|
| `0_self_check.bat` | 不用鏡頭的自我檢查：手勢辨識（練習樣本）、語音指令 79 句、觸發邏輯 14 項、應用程式模式 77 項 |
| `1_start_dry_run.bat` | **模擬模式**：鏡頭＋麥克風都會運作，但只顯示「會做什麼」，不會真的按鍵 |
| `2_start_airtouch.bat` | 正式使用：先開好 YouTube 影片，再啟動 |
| `3_start_text_mode.bat` | 打字模式：在黑色視窗打「快轉20秒」代替說話 |
| `4_collect_samples.bat` | 收集自己的手勢樣本（輸入標籤，例如 `王小明_近_白天`） |
| `5_evaluate_gestures.bat` | 評估 `data/` 裡所有樣本：辨識率、混淆矩陣、誤觸率 |
| `6_make_skip_template.bat` | 「略過」按鈕認不到時，截圖做新的按鈕樣板 |
| `7_presentation_mode.bat` | 上台簡報用：固定在 PowerPoint 模式（不會因為切到別的視窗而改變） |

`0_self_check.bat` 的預期結果：練習樣本整體準確率 96.5%（一般樣本 100%、困難樣本 80%）、語音 79/79、觸發 14/14、模式 77/77
（沒有安裝 pyautogui 時模式測試是 71/71，少了快捷鍵名稱檢查）。

## 三、應用程式模式
| 模式 | 怎麼認出來（視窗標題含有） | 食指向右／左 | 手掌張開 | 剪刀手 | 大拇指朝上／下 |
|---|---|---|---|---|---|
| YouTube | YouTube | 快轉／倒退 10 秒 | 播放／暫停 | 按下「略過」 | 音量 |
| PowerPoint 簡報 | PowerPoint | 下一頁／上一頁 | 黑畫面切換 | 雷射筆 | 音量 |
| PDF 閱讀 | .pdf、Adobe Acrobat | 下一頁／上一頁 | 恢復頁面大小 | — | 放大／縮小 |
| Teams／Zoom／Meet | Microsoft Teams、Zoom Meeting、Meet - | 向右＝舉手 | 麥克風開關（1 秒） | 鏡頭開關（1 秒） | 音量 |

- 比對順序：PowerPoint → Teams → Zoom → YouTube → Meet → PDF，先符合的優先。
- PDF 模式用 `PageDown`／`PageUp` 換頁、`Ctrl+0` 恢復大小：Acrobat 是「符合頁面」，Edge 是「縮放 100%」；Edge 要在檢視設定選「單頁」，換頁才會剛好一頁。
- 自動切換：每 0.5 秒看一次最前面的視窗；切到記事本這類不認得的程式時，維持原本的模式。
- 手動切換：視窗按 `p` 換到下一個模式（會變成「固定」），按 `a` 回到自動；也可以說「切換到簡報模式」「自動切換」。
- 會議軟體的快捷鍵：Teams `Ctrl+Shift+M`（麥克風）、`Ctrl+Shift+O`（鏡頭）、`Ctrl+Shift+K`（舉手）；
  Zoom `Alt+A`、`Alt+V`、`Alt+Y`；Meet `Ctrl+D`、`Ctrl+E`、`Ctrl+Alt+H`。
- 每個模式的手勢、快捷鍵都寫在 `config.json` 的 `profiles`，可以自己新增模式（例如 VLC、Spotify）。

### PowerPoint 進階功能（需要安裝 Microsoft PowerPoint）
- 懸浮視窗顯示「第 3／12 頁」；按 `n` 顯示這頁的備忘稿（講者提示）。
- 說「跳到第五頁」直接跳頁；說「跳到結論那頁」會找標題（找不到再找內文）含有「結論」的投影片。
- 這些功能透過 PowerPoint 的程式介面（`ppt_com.py`）完成；沒有安裝時，跳頁會改用「輸入頁碼＋Enter」，其他快捷鍵照常可用。
- 放映時的快捷鍵：`→`／`←` 換頁、`B` 黑畫面、`W` 白畫面、`Ctrl+L` 雷射筆、`Ctrl+P` 畫筆、`Ctrl+A` 一般游標、`E` 清除筆跡、`Esc` 結束。
  這些按鍵要在「投影片放映」中才有作用；編輯畫面可以先說「開始放映」或「從這頁放映」。

## 四、YouTube 模式的手勢
| 手勢 | 維持 | 動作 |
|---|---|---|
| 手掌張開 | 0.5 秒 | 播放／暫停 |
| 食指向右 | 0.35 秒（繼續比著每 1 秒再一次） | 快轉 10 秒 |
| 食指向左 | 0.35 秒（每 1 秒再一次） | 倒退 10 秒 |
| 大拇指朝上 | 0.3 秒（每 0.25 秒再一次） | 音量調大 |
| 大拇指朝下 | 0.3 秒（每 0.25 秒再一次） | 音量調小 |
| 剪刀手 | 0.6 秒 | 按下「略過」（有出現按鈕時） |
| 握拳 | 1.5 秒 | 手勢鎖定／解鎖（鎖定時其他手勢都不會觸發） |

手放太遠（手腕到中指指根的長度小於畫面高度的 10%）不會觸發，避免後面走過的人或螢幕裡的手被誤認。
手勢和動作的對應寫在 `config.json` 的 `profiles` → 各模式的 `gestures`，可以自己改。

## 五、語音指令（例句）
| 類別 | 例句 |
|---|---|
| 播放／暫停 | 暫停、繼續播放 |
| 快轉／倒退 | 快轉20秒、往前一分鐘、快轉一分半、倒退十五秒、往後快轉20秒 |
| 音量 | 大聲一點、音量調大五格、小聲一點、靜音、影片靜音 |
| 畫面 | 全螢幕、開字幕、下一部、播快一點、減速 |
| 廣告 | 跳過廣告、略過 |
| 網站與點歌 | 打開YouTube、我想聽周杰倫的稻香、換播五月天、關閉這首換播稻香、關閉這首 |
| 簡報 | 開始放映、從這頁放映、下一頁、上一張、跳到第五頁、跳到結論那頁、最後一頁、黑畫面、白畫面、雷射筆、畫筆、擦掉、箭頭、結束放映 |
| PDF | 下一頁、上一頁、放大、縮小、整頁、最後一頁 |
| 會議 | 麥克風、靜音（會議模式下＝麥克風）、電腦靜音、關鏡頭、舉手 |
| 模式 | 切換到簡報模式、PDF 模式、會議模式、影片模式、自動切換 |
| 系統 | 鎖定手勢、啟用手勢、關閉程式 |

同一句話在不同模式可能做不同的事，例如「靜音」在會議模式是關麥克風，其他模式是電腦靜音；
目前模式沒有的功能會顯示「○○模式沒有○○」，不會亂按鍵。

完整測試句在 `voice_test_phrases.csv`。想避免聊天時誤觸，可在 `config.json` 設定喚醒詞，例如 `"voice_wake_word": "小觸"`，
之後要說「小觸快轉20秒」才會動作。

## 六、視窗按鍵
`q` 結束、`g` 手勢鎖、`v` 語音開關、`p` 換模式、`a` 自動切換模式、`n` 簡報備忘稿、`t` 視窗置頂、`o` 透明度（100／75／50%）、`s` 小視窗、`h` 說明、`d` 除錯資訊（顯示每根手指伸直或彎曲）。

## 七、config.json 重要設定
| 設定 | 預設 | 說明 |
|---|---|---|
| `camera` | 0 | 鏡頭編號（外接鏡頭可能是 1） |
| `min_palm_ratio` | 0.1 | 手腕到中指指根的長度，至少要占畫面高度的比例；太遠不理會 |
| `straight_deg` | 40 | 手指兩段夾角小於幾度算「伸直」 |
| `thumb_out_ratio` | 0.5 | 大拇指尖離食指根多遠（以手掌大小為單位）算「伸出」 |
| `direction_tolerance_deg` | 40 | 食指向左右、大拇指朝上下，方向可以偏幾度 |
| `smooth_frames` | 5 | 取最近幾格的多數決，減少跳動 |
| `cooldown_sec` | 0.6 | 一個動作之後，幾秒內不觸發別的動作 |
| `lock_hold_sec` | 1.5 | 握拳多久切換手勢鎖 |
| `voice_threshold_ratio` | 3.0 | 音量超過背景雜音幾倍算開始說話；環境吵就調大 |
| `voice_end_silence_sec` | 0.8 | 安靜多久算說完 |
| `voice_wake_word` | 空白 | 喚醒詞，空白代表不需要 |
| `skip_match_threshold` | 0.8 | 「略過」按鈕樣板的相似度門檻 |
| `window_topmost` | true | 啟動時視窗置頂 |
| `default_profile` | youtube | 啟動時的模式 |
| `auto_switch_profile` | true | 依最前面的視窗自動切換模式 |
| `profiles` | — | 每個模式的視窗關鍵字、快捷鍵、語音對應與手勢 |

## 八、資料夾
| 位置 | 內容 |
|---|---|
| `data/` | 手勢樣本（只有關節點座標，沒有照片） |

## 九、程式檔案
- `airtouch.py`：主程式（鏡頭、畫面、置頂視窗、紀錄）
- `gestures.py`：手勢判斷與觸發邏輯（蓄力、重複、冷卻、手勢鎖）
- `voice_listener.py`：麥克風錄音、判斷一句話的開始與結束、語音辨識
- `voice_commands.py`：把文字變成動作
- `actions.py`：依模式決定動作、切換視窗、按鍵、開網頁、找「略過」按鈕
- `ppt_com.py`：PowerPoint 程式介面（頁碼、備忘稿、跳頁、依標題找投影片）
- `collect_samples.py`、`evaluate_gestures.py`、`make_demo_samples.py`：收集與評估手勢
- `test_voice_commands.py`、`test_trigger.py`、`test_profiles.py`：自動測試
- `make_skip_template.py`：製作「略過」按鈕樣板

## 十、隱私與安全
- 程式不錄影、不存照片；樣本只存關節點座標。
- 視訊會議中，手勢與語音會開關麥克風、鏡頭；正式會議前先在測試會議練習，不用時握拳鎖定手勢。
- 語音會送到 Google 辨識，不要在程式開著時說私人資訊；不用語音時按 `v` 關閉。
- 拍攝成果影片前，先取得入鏡者同意。
- 把滑鼠快速移到螢幕角落，可以緊急中止自動按鍵（pyautogui 的安全機制）。
