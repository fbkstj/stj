考題數位化重製工作流

從紙本、PDF、手寫考卷出發:數位化 → 審題 → 修題與重新命題 → 詳解 → 排版輸出 → 上網。一套可重複使用的做法。

整體流程

每一關都有明確的輸入與輸出,後一關只用前一關確認過的結果。

收件

原始檔:掃描 PDF、手寫稿、照片。先確認用途(自用、校內、公開)與版權。

數位化

逐題轉成文字,選項與括號作答格保留;電路圖、波形、表格另行重繪。

審題

檢查題意、數據、單位、答案是否唯一,列出疑義清單。

修題 / 重新命題

修正錯誤;或保留考點、更換數值與情境,產生模擬題。

詳解

計算步驟、逐選項判斷對錯、標註假設與疑義。

排版輸出

照原卷格式或指定格式輸出 B4 PDF(詳解版、題目版)與網頁版。

發佈

放上網頁。涉及他人試題者先評估版權,不放公開位置。

各階段輸入與輸出

階段輸入輸出檢查點
數位化掃描 PDF / 手寫稿題目文字、選項、圖形清單題號、選項、單位、正負號、上下標是否抄錄正確
圖形重繪圖形截圖(放大 200–250 dpi)標準符號 SVG 向量圖節點、極性、電流方向與原圖逐項對照
審題數位化題目疑義清單、修正建議答案是否唯一、數據是否可解、題目文字是否有筆誤
修題 / 命題確認後的題目修正題或新題新數值是否整除、選項是否有合理誘答
詳解題目與答案步驟式詳解用第二種方法交叉驗算,答案一致才採用
排版輸出題庫資料PDF(B4)、HTML版面不超出紙張、圖不被截斷、字型正常

審題檢核表

題目本身

  • 題幹有沒有筆誤(例如把「作用區」寫成「飽和區」)
  • 單位是否一致(W 與 mW、kΩ 與 Ω)
  • 數據是否足以求解,有無多餘或缺漏條件
  • 圖與文字描述是否一致(元件值、極性、電流方向)

答案與選項

  • 正確選項是否唯一;若有兩個合理選項,標為疑義題
  • 誘答選項是否對應常見錯誤(公式用錯、忽略負載效應等)
  • 「約為」「大約」的題,檢查近似值是否合理
  • 答案要以不同方法交叉驗算
疑義題處理原則:不替命題者「猜」標準答案。詳解中寫明採用的假設、備選答案,並建議向命題者確認。

修題與重新命題

修題

  • 只改有問題的地方,其餘維持原貌
  • 改後重新計算答案與詳解
  • 保留修改紀錄(改了什麼、為什麼)

重新命題(模擬題)

  • 保留考點與難度,更換數值、情境、圖形
  • 數值設計成容易驗算(整除、不需計算機)
  • 選項依常見錯誤設計,避免與原題數字雷同
  • 原題只當範本,不直接複製

圖形重繪規範

  • 輸出為 SVG 向量圖,黑白線稿,列印與縮放都清晰
  • 電阻用鋸齒符號;電池長板為正極;電流源為圓內加箭頭;接地、節點用圓點
  • BJT 標示基極、集極、射極與箭頭方向(NPN 向外、PNP 向內)
  • 變壓器、二極體(含稽納、發光)、電容、示波器格線、電錶刻度都用統一樣式
  • 文字標籤的下標統一處理(R1、VCC),避免與線條重疊
  • 重繪後與原圖逐元件對照,確認節點連接與極性

詳解寫法

計算題

  • 先說明用哪個定理或模型
  • 列式 → 代入 → 結果,每一步獨立一行
  • 必要時補一行「速算」或另一種解法

觀念題

  • 逐選項寫「○ / ×」與一句理由
  • 錯的選項說明錯在哪裡,正確說法是什麼
  • 有爭議的選項另加「題目疑義」備註

版面與輸出

項目做法
紙張B4(257 × 364 mm)直式
原卷格式頁首標題、班級姓名座號列、資訊表格、括號作答格、單欄或雙欄,依原卷還原
詳解版解答表 + 詳解;或詳解直接寫在每題下方(自己看的版本)
題目版只有題目,無答案與詳解,可發給學生
字型明體(Noto Serif TC),產生 PDF 時嵌入字型
檢查用瀏覽器自動檢查有無超出版面、圖是否被截斷,再人工逐頁目視
格式PDF 供列印與傳送,HTML 供網頁瀏覽

資料安全與版權

  • 公開位置不放他人試題與答案(公開網站、公開程式庫都算公開)。
  • 市售模擬考、他校考卷屬他人著作,僅供個人研讀;不改作後散布。
  • 自編試題要公開前,先確認尚未用於正式考試,避免洩題。
  • 只放「方法與流程」的頁面可以公開;成品檔案用私人方式交付(檔案傳送、私人雲端)。

提示詞範本

交給 AI 處理一份考卷時可直接使用,把括號內改成自己的需求。

我上傳了一份【科目】考卷的【掃描 PDF / 手寫稿】,請依下列步驟處理:
1. 數位化:逐題轉成文字,保留題號、選項、單位;電路圖與波形請重繪成黑白標準符號 SVG 向量圖。
2. 審題:列出題目筆誤、單位問題、答案不唯一或缺條件的題目,先不要自己猜答案,標成疑義題。
3. 修題 / 命題:【只修錯誤 / 保留考點重新出模擬題】,數值要易於驗算。
4. 詳解:計算題寫出列式與代入;觀念題逐選項標 ○/× 並說明理由;用另一種方法交叉驗算。
5. 排版:B4 直式,【仿原卷格式 / 詳解寫在每題下方】,輸出【詳解版 PDF、題目版 PDF】。
6. 最後列出你的假設與需要我確認的疑義題。
注意:成品只傳給我,不要放到公開的程式庫。
