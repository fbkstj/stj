試題說明：
Ａ、圖 1 除紅色粗體電路之外，為賽前已依照『選手自備器具材料清單』裝配並攜帶進場之介面卡（含 RTC 模組排針），請依照圖 1 完成全部之個人電腦 USB、藍牙介面卡製作及控制電路，否則以零分計算。
Ｂ、請使用藍牙模組連接個人電腦與 USB、藍牙介面卡（以下簡稱介面卡），並撰寫程式，使介面卡具有下列功能：
1. CPU LED 燈閃爍表示系統正常運行。為模擬藍牙狀態，Red LED 須區隔連線狀態：（a）**未連線狀態**：呈**快速閃爍**（每秒 5 次，即亮 100ms / 滅 100ms）；（b）**已連線狀態**（與電腦端連線成功後）：呈**短暫閃光模式**（每 2 秒閃亮 1 次，即亮 100ms / 滅 1900ms）。
2. TFT 顯示器初始化顯示為，第一行 TYAI，第二行為 C2XX，XX 為崗位號碼，延遲約 2 秒後自動進入選單模式（Code Edit／Unlock／Breathing LED／Time）；主選單畫面不再常駐顯示日期時間，且右下角同步以英文顯示連線狀態（未連線顯示 DISC，已連線顯示 CONN）。主選單中之 Unlock 選單須與時間同步狀態連動：未同步前顯示為紅色且無法進入該選單；與電腦端成功連線同步且時間誤差在 3 秒內時，選單轉為綠色並啟用功能。
3. 進入 Breathing LED 選單，Red、Yellow、White，三色選擇依照崗位號碼個位數，進行不同配色並持續閃爍，直到按下 Back 按鍵回上一層選單時停止。
4. 進入 Code Edit 選單，可分別選擇編輯 Root Seed 或 User Seed，各為四位數十六進制數值，數值配置方式透過按鈕上、下鍵進行設定，每一數值設定完成後按 Enter 會切換為下一位接續配置，四位數配置完成後按下 Enter 會呈現 "Code Save!"，按下 Back 按鍵則回上一層選單。將介面卡電源移除後重新進入可分別顯示前次儲存於 EEPROM 之 Root Seed 與 User Seed。
5. 進入 Time 選單，呈現初始化時間為：23/10/10-W(2) 13:14:55，且時、分、秒持續更新，按下 Back 按鍵則回上一層選單。將介面卡電源移除後重新供電，再次進入 Time 選單時，應由 RTC 接續呈現斷電期間持續累計後之正確目前時間，不歸零、不需等待電腦重新連線同步。
6. （a）藍牙模組名稱顯示為 XX-HH，XX 為崗位號碼，HH 為崗位號碼轉換為十六進制數值。（b）程式執行後，電腦執行視窗畫面於最上方標題列顯示『115 學年度（模擬） 工業類科學生技藝競賽 電腦修護職種 北科附工 第二站 崗位號碼：XX』，須正確顯示於最上方標題。

7. （a）電腦執行視窗畫面顯示 COM Port 清單，點選 Refresh 時會自動更新電腦系統內所偵測之連接埠，電腦執行視窗不需被關閉即可更新下拉式選單 COM Port 清單。（b）電腦執行視窗畫面點選 Connect，畫面顯示 Disconnect，並同時開啟 Now Time，且同步至介面卡 YYYY-MM-DD HH:MM:SS 更新時間以秒為單位，同一時間點寫入介面卡 RTC。
8. 電腦執行視窗新增 Root Seed、User Seed 輸入欄位，選手須將介意卡 Code Edit 中設定之相同數值輸入電腦端；連線後電腦依 RTC 同步時間，每 30 秒運算並持續顯示 Current OTP (root)、Current OTP (user)（公式：時間值＝分鐘×100＋秒數捨去至30倍數；OTP = ((Seed XOR 時間值) * 31337) AND 0xFFFF，以4位十六進制表示，字母大寫）。送出 OTP 後，介面卡同時比對自身算出之 root／user OTP：符合 root 者開啟 c:\setup 與 c:\public；符合 user 者僅開啟 c:\public；皆不符合則兩者皆不開啟。TFT 依序呈現 "Waiting for OTP..." → "OTP: XXXX / Verifying..." → 結果（Unlocked (ROOT) / Unlocked (USER) / Access Denied）。WS2812-8bits 成功閃爍綠燈三次、失敗閃爍紅燈三次後自動熄滅。
9. 電腦執行視窗中顯示目前通訊交握狀態日誌，需逐一顯示連線、時間同步、Seed 輸入、時間值計算、雙方即時 OTP、送出之 OTP、介面卡比對結果與開啟之資料夾等所有參數，以利未來除錯使用，不得省略任一步驟。

試題需求：
NTNU 委託 TYAI 進行產品開發，產品開發基於 ATmega328P，專案須採用藍牙通訊元件進行遠端控制，老陶為專案經理，老王為技術經理，開發一套可提供用戶使用於個人資料保全方案與控制周邊環境系統之產品。本次模擬試題新增 RTC 即時時鐘模組，並將原本單一使用者的保全機制，升級為 Root／User 雙層級、以時間為參數的一次性密碼（OTP）驗證方式，使個人資料保全中可有更精確之權限控管與時效性。
以下為功能需求與說明：
1. 設計 CPU LED 運行指示燈。未與電腦端連線時，Red LED 呈快速閃爍（頻率 5Hz）以模擬配對中狀態；與電腦端成功連線後，自動轉為短暫閃光模式（每 2 秒閃亮 1 次, 即亮 100ms / 滅 1900ms）以模擬已連線狀態。
2. TFT 顯示器初始化顯示為第一行 TYAI，第二行為 C2XX，XX 為崗位號碼，延遲 2 秒後自動進入 MENU（選單模式），並可使用 "UP"、"Down"、"Enter"、"Back" 按鍵進行 MENU 與功能切換，且於所有 TFT 畫面右下角同步以英文顯示當前藍牙連線狀態：未連線時顯示 DISC，連線成功後顯示 CONN。此外，主選單中之 Unlock 選項預設呈紅色且處於禁用狀態（按 Enter 無反應）；當介面卡與電腦端成功進行時間同步，且兩端時間誤差在 3 秒內時，該選項字體須轉為綠色且功能啟用，允許按 Enter 鍵進入解鎖流程。
