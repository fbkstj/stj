題目 1: 溫度警報器

🎯 考試需求：
1. 建立一個應用程式，輸入攝氏溫度 (C)。
2. 按下按鈕後，將其轉換為華氏溫度 (F)。
3. 公式： F = C × 1.8 + 32。
4. 新增功能： 如果轉換後的華氏溫度超過 100 度，結果文字必須變成 紅色，並在後面加上「(過熱警告)」。否則文字為黑色。

題目 2: 三角形面積計算

🎯 考試需求：
1. 設計介面讓使用者輸入三角形的「底」與「高」。
2. 按下按鈕後，計算並顯示三角形的面積。
3. 公式： 面積 = (底 × 高) ÷ 2。
4. 防呆功能： 如果底或高輸入了負數，請顯示「輸入錯誤：數值不能為負」。

題目 3: 因數計數器

🎯 考試需求：
1. 輸入一個正整數 N。
2. 使用迴圈找出該數字所有的因數。
3. 變更需求： 除了列出所有因數外，請在最後一行顯示**「總共有幾個因數」**。
提示：你需要一個額外的變數來計數 (count)。
找因數與計數

題目 4: 偶數累加器

🎯 考試需求：
1. 輸入一個整數 N。
2. 計算從 1 到 N 之間，所有 偶數 的總和。
3. 例如輸入 10，計算 2+4+6+8+10 = 30。
4. 提示：可以使用迴圈搭配 remainder (餘數) 積木，或者調整迴圈的間隔 (step)。
偶數累加

題目 5: 數字金字塔

🎯 考試需求：
1. 輸入層數，使用雙層迴圈 (Nested Loop) 輸出圖形。
2. 變更圖形： 不要輸出 #，改為輸出 數字。
3. 第 1 層顯示 "1"。
4. 第 2 層顯示 "12"。
5. 第 3 層顯示 "123"。
提示：內層迴圈的變數 j 剛好就是要顯示的數字。
數字金字塔
