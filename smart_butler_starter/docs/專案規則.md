# 專案規則（每一關開始前，AI 助手都要先讀這份檔案並遵守）

1. 只修改本專案資料夾內的檔案。
2. 金鑰、Token、Webhook 只放 `.env`；程式、設定檔、提示語、截圖都不可出現明碼。`.env` 不可上傳。
3. 未經同意，不可開啟攝影機或麥克風、不可發訊息到正式 Discord 頻道、不可控制真實家電。
   開發與測試一律用 `demo/` 的示範影片與模擬資料；Discord 先用 `dry_run: true` 或練習伺服器的測試頻道。
4. 要安裝新套件、刪除檔案、變更資料庫結構前，先列出內容並等我同意。
5. 相容 Windows：路徑用 `pathlib`，檔案一律 UTF-8，中文路徑要能正常運作
   （讀寫圖片用 `np.fromfile`＋`cv2.imdecode`、`cv2.imencode`＋`tofile`；PowerShell 腳本存成 UTF-8 with BOM）。
6. 影像、人臉、對話紀錄、醫療資料只存本機，要有保存天數，並提供隱私模式。
7. 新模組一律繼承 `core/module.py` 的 `Module`，只發出事件；存檔、通報、顯示交給共用服務。
   要處理別的模組的事件，用 `listens`，不要自己呼叫 `bus.subscribe`。
8. 每完成一項就更新 `PROGRESS.md`；每一關結束都要停下來回報，附上實際執行的指令與輸出。
9. 改了程式就執行 `python tests/run_all_tests.py`，全部通過才算完成。
