Altera MegaWizard + AHDL
七段顯示與鍵盤掃描實作

🏫 製作者：簡樹桐老師 ／ 市立楊梅高中

📚 課程類別：數位邏輯與 CPLD 實作

🔧 晶片：EPM3064LC44-10 ｜ 時脈：4 MHz

LPM_COUNTER (C12) LPM_DECODE (DECODE24) LPM_LATCH (LATCH4) 7Asegment (AHDL 自建) OR3 / NOT 邏輯閘
2
整體架構說明
  • C12：12位元遞增計數器，提供掃描節拍與顯示資料來源。
  • q[11..10] → DECODE24 → R0~R3（鍵盤列掃描）。
  • q[13..10] → LATCH4.data[3..0]（顯示資料輸入）。
  • LATCH4.gate ← OR3(C0,C1,C2)（任一鍵按下鎖存）。
  • LATCH4.q[3..0] → 7Asegment（AHDL自建七段顯示器）。
3
MegaWizard 元件設定
🧩 C12 / LPM_COUNTER
  • Data width = 12，Up Counter，開啟 clock、clk_en、q。
  • clock ← CLK（4 MHz），clk_en ← NOT(外部使能)。
🧩 DECODE24 / LPM_DECODE
  • LPM_WIDTH = 2，LPM_DECODES = 4。
  • data[1..0] ← q[11..10] → eq0~eq3 → R0~R3。
🧩 LATCH4 / LPM_LATCH
  • Data width = 4，啟用 gate（由 OR3 控制）。
  • data[3..0] ← q[13..10]，輸出 q[3..0] → 7Asegment。
4
4 MHz 掃描頻率分析
  • q[11..10] 產生掃描頻率：4 MHz / 4096 ≈ 976 Hz。
  • 四列輪掃 → 每列約 976/4 ≈ 244 Hz。
  • 約 4 ms 完成一輪掃描，肉眼顯示穩定不閃爍。
  • 高位 (q[13..10]) 慢速變化，用於顯示資料或模擬鍵盤輸入。
5
鍵盤掃描的定義與原理
  • 鍵盤掃描（Keyboard Scanning）是以行與列構成矩陣，透過控制端逐列輸出訊號、逐行讀取輸入狀態。
  • 每個交叉點有一顆按鍵，按下時導通列與行。
  • 控制端依序使每列為高，並偵測行端(C0~C2)是否為高來判斷按鍵。
  • 在乙級題中：
  • R0~R3：由 DECODE24 提供掃描信號（高有效）。
  • C0~C2：輸入端，未按時=0，按下導通=1。
  • OR3(C0,C1,C2)：任一鍵按下即觸發 LATCH 鎖存資料。
  • 優點：節省I/O腳位、顯示穩定、可整合顯示與掃描。
6
鍵盤掃描實體接線與順序
  • 掃描順序：147* → 2580 → 369#。
  • R0~R3 為列輸出（由 DECODE24 控制，高有效）。
  • C0~C2 為行輸入（預設接地，按下時導通=1）。
  • OR3(C0,C1,C2)：任一鍵按下即觸發 LATCH4.gate。

C0 C1 C2 R0 R1 R2 R3

7
鍵盤掃描信號對應表

由計數器位元 q[13..10] 產生掃描訊號，對應鍵盤矩陣表：

q[13]q[12]q[11]q[10]掃描列對應鍵位
0000R01 (C0) ／ 2 (C1) ／ 3 (C2)
0101R14 (C0) ／ 5 (C1) ／ 6 (C2)
1010R27 (C0) ／ 8 (C1) ／ 9 (C2)
1111R3* (C0) ／ 0 (C1) ／ # (C2)
8
為什麼 q[13..10] 接到 LATCH4
  • q[13..10] 為計數器高位，變化較慢，適合作為顯示資料來源。
  • 高位輸出每次組合代表不同4-bit資料（0000~1111）。
  • 當 OR3 為高時，LATCH4 鎖存該組資料 → 穩定顯示。
  • q[13]/q[12] 亦可接至 C2/C1 模擬按鍵信號，自動觸發更新。

AHDL 鍵值編碼對應（H"X"）：

  • H"0"→1, H"1"→4, H"2"→7, H"3"→* （第一行）
  • H"4"→2, H"5"→5, H"6"→8, H"7"→0 （第二行）
  • H"8"→3, H"9"→6, H"A"→9, H"B"→# （第三行）

AHDL：7Asegment 程式
SUBDESIGN 7Asegment ( i[3..0] : INPUT; a,b,c,d,e,f,g : OUTPUT; ) BEGIN TABLE i[3..0] => a,b,c,d,e,f,g; H"0" => 1,0,0,1,1,1,1; -- 按 "1" 顯示 H"1" => 1,0,0,1,1,0,0; -- 按 "4" 顯示 H"2" => 0,0,0,1,1,1,1; -- 按 "7" 顯示 H"3" => 1,1,1,0,0,1,0; -- 按 "*" 顯示 H"4" => 0,0,1,0,0,1,0; -- 按 "2" 顯示 H"5" => 0,1,0,0,1,0,0; -- 按 "5" 顯示 H"6" => 0,0,0,0,0,0,0; -- 按 "8" 顯示 H"7" => 0,0,0,0,0,0,1; -- 按 "0" 顯示 H"8" => 0,0,0,0,1,1,0; -- 按 "3" 顯示 H"9" => 1,1,0,0,0,0,0; -- 按 "6" 顯示 H"A" => 0,0,0,1,1,0,0; -- 按 "9" 顯示 H"B" => 1,1,0,0,1,1,0; -- 按 "#" 顯示 END TABLE; END;

整體運作流程總結
  1. C12 產生時脈（4 MHz）與高位資料來源 q[13..10]。
  2. q[11..10] 控制 DECODE24，依序掃描 R0 → R1 → R2 → R3。
  3. 鍵盤輸入 C0~C2 回傳按鍵狀態（高有效）。
  4. 任一鍵按下 → OR3=1 → 觸發 LATCH4.gate → 鎖存 q[13..10] 的資料。
  5. LATCH4 輸出 q[3..0] → 送入 7Asegment 解碼 → 七段顯示器輸出 a~g。
  6. 顯示內容依鍵盤掃描更新，或模擬輸入持續自動變化。
