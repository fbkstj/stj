⚠️ 官方評審關鍵紅線（未能栓鎖扣 25 分、段碼錯誤每字扣 25 分）：
  • 組別錯誤直接不予評分：七段顯示器未依測試當日抽籤指定的題組顯示其內容（例如抽到 J 組卻顯示 K 組或其他組別內容），則不予評分。
  • 栓鎖要求（-25 分）：鍵盤每一個數字符號應顯示並栓鎖於七段顯示器，若未能栓鎖則扣 25 分。
  • 節段顯示錯誤（每字扣 25 分）： 同一個節段內容顯示不正確，則每一節段扣 25 分（如 a 節段在 12 個數字符號顯示都不正確扣 25 分）；不同數字符號不同段顯示不正確，則每字扣 25 分（如數字 3 的 b 段錯、數字 5 的 f 段錯，共扣 50 分）。一個錯誤僅扣一次不重複扣分。

Step 1 LPM_COUNTER

12位元計數除頻器 (C12)

  • • Data Width: 12 bits
  • • 類型: Up Counter (上數)
  • • Clock: 接外部 4MHz (PIN 43)
  • • 輸出: q[11..10] 送解碼與多工
Step 2 LPM_DECODE

2TO4 顯示位元解碼器

  • • LPM_WIDTH: 2 bits
  • • LPM_DECODES: 4 outputs
  • • 輸入: data[1..0] ← q[11..10]
  • • 輸出: eq0~eq3 依序致能 D0~D3
Step 3 LPM_CONSTANT

8-bit 七段顯示常數 (4組)

  • • 常數設定: 建立 4 顆常數元件
  • • 數值依 J~N: 填入四位數字段碼
  • • LPM_CVALUE: 填入 8 位元段碼值
  • • 輸出: 分別接至 MUX data0x~data3x
Step 4 LPM_MUX

4TO1 8-bit 資料多工器

  • • Data Width: 8 bits
  • • Number of Inputs: 4 inputs
  • • 選擇端: sel[1..0] ← q[11..10]
  • • 輸出: result[7..0] 輸出至 DSS

🧮 掃描除頻公式與視覺暫留原理

4 MHz (石英震盪) ÷ 4096 = 976.56 Hz（總掃描頻率）➔ 4 位數輪掃每位數約 244.14 Hz（每 4.1ms 完成一輪），人眼視覺暫留無閃爍！

💻 自訂顯示元件 7Asegment.tdf (AHDL 語法) 

SUBDESIGN 7Asegment
(
    i[3..0]       : INPUT;
    a,b,c,d,e,f,g : OUTPUT;
)
BEGIN
    TABLE i[3..0] => a,b,c,d,e,f,g;
        H"0" => 1,0,0,1,1,1,1;  -- 按 "1" 顯示 1
        H"1" => 1,0,0,1,1,0,0;  -- 按 "4" 顯示 4
        H"2" => 0,0,0,1,1,1,1;  -- 按 "7" 顯示 7
        H"3" => 1,1,1,0,0,1,0;  -- 按 "*" 顯示 (依J~N抽測變更)
        H"4" => 0,0,1,0,0,1,0;  -- 按 "2" 顯示 2
        H"5" => 0,1,0,0,1,0,0;  -- 按 "5" 顯示 5
        H"6" => 0,0,0,0,0,0,0;  -- 按 "8" 顯示 8
        H"7" => 0,0,0,0,0,0,1;  -- 按 "0" 顯示 0
        H"8" => 0,0,0,0,1,1,0;  -- 按 "3" 顯示 3
        H"9" => 0,1,0,0,0,0,0;  -- 按 "6" 顯示 6
        H"A" => 0,0,1,1,1,0,0;  -- 按 "9" 顯示 9
        H"B" => 1,1,0,0,1,1,0;  -- 按 "#" 顯示 (依J~N抽測變更)
    END TABLE;
END;

🧩 Quartus II MegaWizard 6 大核心精靈元件速查庫

點擊各元件卡片查看精靈分類路徑、參數設定、引腳連線定義與考場避坑技巧

Arithmetic LPM_COUNTER

1. 計數除頻器 (C12)

📍 精靈路徑: Arithmetic > LPM_COUNTER
⚙️ 重要參數:
  • Data width = 12 bits
  • Up counter only (向上計數)
  • 勾選 clock、q 輸出、clk_en (使能)
💡 考場要點: 試題一 clk_en 預設接高電位；試題二 clk_en 可由外部開關控制。
Gates LPM_DECODE

2. 解碼器 (DECODE24)

📍 精靈路徑: Gates > LPM_DECODE
⚙️ 重要參數:
  • LPM_WIDTH = 2 (輸入2位元)
  • LPM_DECODES = 4 (輸出4位元 eq0~eq3)
  • 輸出為 Active High (高有效)
💡 考場要點: 用於試題一 D0~D3 掃描，以及試題二鍵盤 R0~R3 輪流送高電位。
Gates LPM_MUX

3. 多工器 (MUX4TO1)

📍 精靈路徑: Gates > LPM_MUX
⚙️ 重要參數:
  • Width of data input = 8 bits
  • Number of data inputs = 4 (data0x..data3x)
  • sel[1..0] 由 q[11..10] 控制
💡 考場要點: 需注意 8-bit bus 命名（如 data0x[7..0]），避免引腳線寬不匹配。
Gates LPM_CONSTANT

4. 8-bit 常數產生器

📍 精靈路徑: Gates > LPM_CONSTANT
⚙️ 重要參數:
  • LPM_WIDTH = 8 bits
  • 填入 10 進制或 16 進制段碼數值
  • 每題共需建立 4 顆常數
💡 考場要點: 依抽到的 J~N 顯示組別填入正確數字對應之 8-bit 段碼。
Storage LPM_LATCH

5. 4位元栓鎖器 (LATCH4)

📍 精靈路徑: Storage > LPM_LATCH
⚙️ 重要參數:
  • Data width = 4 bits
  • 啟用 gate 控制端（由 OR3 驅動）
  • data[3..0] ← q[13..10]
💡 考場要點: 試題二核心！按鍵放開後 gate=0，仍能穩定鎖存顯示。
AHDL 7Asegment.tdf

6. AHDL 自訂七段元件

📍 建立方式: File > New > AHDL Design File
⚙️ 重要步驟:
  • 存檔檔名必須與 SUBDESIGN 一致（7Asegment.tdf）
  • 執行 File > Create/Update > Create Symbol
  • 在電路圖中雙擊即可放置該元件
💡 考場要點: 語法結尾必須有 END TABLE; 與 END;。
