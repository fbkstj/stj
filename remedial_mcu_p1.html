呼吸燈 × 滑桿

拖曳滑桿就是在 Tinkercad 裡拖曳電位器：滑桿越靠左，呼吸越慢；越靠右，呼吸越快。

目前：中速（約 3.3 秒呼吸一次）

◀ 最左：最慢（6 秒）最右：最快（0.6 秒）▶

可以用滑鼠拖曳，或先點一下滑桿再用鍵盤左右方向鍵微調。

即時數值

電位器讀值512
呼吸週期3300ms
目前亮度0/ 255
analogWrite 值0

亮度就是寫進腳位的 analogWrite 值：0 是全暗，255 是最亮。

亮度隨時間的變化

滑桿往右時，波峰之間變窄，代表同樣時間內呼吸的次數變多。

等效的 Arduino 程式

const int POT = A0;     // 電位器滑桿（中間腳接 A0）
const int LED = 9;      // LED 接可輸出 PWM 的腳位，記得串限流電阻

int brightness = 0;     // 目前亮度 0～255
int step = 1;           // 每次變化的方向：+1 變亮、-1 變暗

void setup() {
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // 每次迴圈都重新讀滑桿，所以拖曳時速度立刻改變
  int pot = analogRead(POT);              // 0～1023

  // 滑桿最左 → 一次呼吸 6000 毫秒；最右 → 600 毫秒
  int period = map(pot, 0, 1023, 6000, 600);

  // 一次呼吸要走 510 步（0→255→0），算出每一步要等多久
  int wait = period / 510;
  if (wait < 1) wait = 1;

  analogWrite(LED, brightness);           // 用 PWM 控制亮度
  brightness += step;
  if (brightness >= 255 || brightness <= 0) step = -step;   // 到頂或到底就換方向

  Serial.println(pot);
  delay(wait);
}

這段程式的換算方式和上面的動畫完全一樣：map(pot, 0, 1023, 6000, 600)。

課堂操作方式

  1. 先把滑桿拉到最左邊，請學生數一次呼吸要幾秒（約 6 秒），並看「呼吸週期」變成 6000 毫秒。
  2. 再慢慢往右拖曳，讓學生同時注意三件事：燈呼吸變快、週期數字變小、下方波形變密。
  3. 最後對照程式裡的 map(pot, 0, 1023, 6000, 600)，說明「滑桿位置 → 週期 → 每一步的等待時間」這條換算鏈。
